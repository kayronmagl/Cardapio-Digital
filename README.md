# Cardápio Digital - Tobia's Lanches

Nova versão do cardápio do Tobia's Lanches, com leitura pelo Supabase, carrinho, checkout e envio do pedido formatado para o WhatsApp.

## O que mudou

- Cardápio conectado ao schema novo do Supabase (`menu_*`).
- Produtos, categorias, adicionais, horários, Pix, entrega e dados da loja lidos do banco atual.
- Painel administrativo para editar produtos, adicionais, disponibilidade e combos.
- Carrinho com delivery, retirada e pedido no local.
- Interface responsiva para uso principal no celular.

## Deploy

Projeto estático pronto para Vercel.
